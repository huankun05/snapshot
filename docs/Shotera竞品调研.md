## 一、设置面板总体结构

独立设置窗口「Shotera 设置」，Win11 Fluent 浅色风格，蓝色 accent：

- **左侧固定导航栏**（10 个分区）：通用 / 截图 / 贴图 / AI 能力 / 输出 / 热键 / 演示 / 更新 / 隐私与诊断 / 关于
- **右侧内容区**：白色圆角卡片按主题分组；每个设置项 = **加粗标题 + 灰色说明文字 + 右侧控件**，
  说明文字写清三件事：行为是什么、何时生效（"切换后立即生效"）、副作用/兼容性（"「保留透明」兼容
  Photoshop、Figma 等；「白色背景」兼容不支持透明的聊天与办公软件"）
- **控件选型纪律**：二选一用分段按钮（开机启动、系统主题、托盘图标）；开关用 toggle；
  3+ 选项用下拉；模型选择用**单选卡片组**（带「内置」/「需下载 · 约 xxxMB」徽章）；
  数量用 -/+ 步进器；路径/模板类输入带**实时预览**行
- 全部改动即时生效并持久化，无"确定/取消"按钮

### 2.4 AI 能力
| 设置 | 控件 | 说明要点 |
|---|---|---|
| 截图后自动提取文字 | toggle（默认关） | 框选确定后自动以**精简模式**识别并**就地显示**；手动点按钮不受影响 |
| AI 抠图模型 | 单选卡片 ×4 | U2Net·极速（内置）/ ISNet·高质量（需下载 ~179MB）/ **RMBG-1.4·推荐（内置）** / RMBG-2.0·最新（需下载 ~366MB） |
| 图片翻译服务 | 服务卡片 ×N | 百度图片翻译 V2.0（推荐·**内置默认额度可免费使用**·支持 V2.0 高精擦除和 V1 经典版）/ 有道翻译（99 语种·「当前使用」徽章·大模型翻译中英日韩）；带彩色状态点 |

**对我们最重要的两条**：① 模型卡片的「内置 vs 需下载+体积」呈现方式，是我们今后任何模型
下选择 UI 的现成范式（对比我们：模型全内置，但"OCR 内存策略三档"可以用同款卡片表达）；
② 翻译服务卡片的「推荐/当前使用」徽章 + 状态点，直接套用到我们云/本地 MT 双引擎选择。

### 2.6 热键（7 项全局热键）
| 功能 | 默认键 | 说明要点 |
|---|---|---|
| 截图 | F1 | 点击「修改」后按下按键/组合键（支持 F1 等单键），Esc 取消 |

| 贴图 | F3 | 贴剪贴板（图像/文本/颜色）为置顶悬浮图；**剪贴板未变时改为恢复最近关闭的贴图** |

### 2.7 演示（此前只记了"需调研 API"，本次截图给出实现答案）
总开关 + 「还原」按钮；提示条说明：开启后按此套**预设**套用，退出一键还原；未开启时仅保存配置。

| 预设 | 实现路径评估 |
|---|---|
| 隐藏桌面图标 | 切换桌面 ListView 的可见性（经典方案，`FindWindow` Progman/WorkerW + `SW_HIDE`） |
| 系统主题 浅色/深色 | 写注册表 `Personalize AppsUseLightTheme/SystemUsesLightTheme` + 广播 WM_SETTINGCHANGE（等于系统个性化设置） |

| **新建虚拟桌面** | **演示时新建空白虚拟桌面并切换过去，原有窗口留在旧桌面不受打扰，退出自动关闭并切回**——比单纯隐藏图标更彻底，是演示模式的"正确答案"。实现走 VirtualDesktop COM 接口（IVirtualDesktopManagerInternal，未公开但成熟，社区有现成 helper DLL） |
| 自动隐藏任务栏 | AppBar 状态切换（SHAppBarMessage ABM_SETSTATE） |

## 四、我们的设置面板设计方案（v1 提案）

### 4.1 现状与差距
独立应用目前零设置 UI：托盘只有「截图/退出」，热键读 store JSON（`SCREENSHOT_HOTKEY_STORE_KEY`），
OCR 引擎/翻译语言靠截图面板内的内联下拉。`store:read`/`store:write` IPC 已就绪，
所以设置窗口只是纯 UI 工作，不需要新后端。

### 4.2 结构（比 Shotera 收敛为 6 个分区）
| 分区 | 内容 | 备注 |
|---|---|---|
| 通用 | 界面语言（zh/en，capture.js 已有内联字典）、开机自启、截图热键入口提示 | 主题暂缓（我们的 UI 全是浮层，不依赖应用主题） |
| 截图 | 截图热键（键帽捕获交互）、截图完成后行为、快捷键提示开关、选区圆角 | |
| OCR · AI | 识别引擎（RapidOCR/Tesseract/云）、**内存策略三档**（常驻/截图触发预热/按需，§3.6 移植项的 UI 载体）、截图后自动识别开关、智能识别/表格识别开关、UI 噪音过滤开关 | 用 Shotera 模型卡片样式表达内存三档 |
| 翻译 | 翻译引擎（本地 Hy-MT2/云）、默认目标语言、引擎状态徽章（模型已加载/服务运行中） | 卡片化参考 2.4 |
| 贴图 | 可恢复贴图数、默认透明度/缩放行为 | 依赖借鉴项 #1 落地 |
| 输出 | 文件名模板 + 实时预览、快捷保存目录、自动保存开关 | |
| 关于 | 版本、构建标识（v4-align 等服务版本）、打开日志目录 | 合并 Shotera 的「关于+隐私诊断」 |

### 4.3 实现要点
- `settings.html` + `settings.js` + `app/settings.ts`（或并入 main.ts）：普通 BrowserWindow，
  复用截图页既有模式（cwd 资源定位 + store IPC），**不需要打包器/框架**，与 capture/pin 同构
- 控件规范照抄 Shotera：标题+说明+右控件；二选一分段按钮；热键键帽捕获态+绿勾；
  模板输入带预览行；全部即时生效写 store
- 入口：托盘菜单「设置…」+ 截图面板「⚙」按钮（二期）
- 迁移视角：设置键名沿用 `SCREENSHOT_HOTKEY_STORE_KEY` 等既有 store 键，移回 Xiyue 时
  设置页对应并入 Xiyue 设置窗口的截图分区（`storeConfig-screenshot-excerpt.ts` 已摘录全部键名）

## 六、截图交互与工具栏盘点（2026-09-15 第二批，5 张实拍）

### 6.1 取色放大镜（Snipaste 同款，替代我们色环的升级方向）
截图选区状态下的屏幕取色：**方形放大镜**（深色面板）+ 蓝色十字定位线 + 中心方格像素光标；
放大镜下方直接显示 **坐标 (652, 297) + 色块 + 色号 #161616**；
快捷键提示就地显示：**Press C to copy / Shift 切换 HEX→RGB→HSV 格式**。
- 对比我们：现在是色环取色器（RingPicker），无坐标、无格式切换、无快捷复制
- 借鉴价值 ★★★：放大镜 + 色号直显 + C 复制 + Shift 切格式，是 Snipaste 验证过的成熟交互，
  纯前端实现（放大镜就是放大绘制的截图帧 + getImageData 取像素）

### 6.2 选区与智能选中
- 选区四角 + 边中点共 8 个白色方形手柄，蓝色 1px 边框；**左上角尺寸标签**（1466 × 64）
- **智能选中**：悬停自动检测——窗口级 + **UI 元素级**（按钮/输入框等控件）+ 文字块，
  高亮框跟随（对应设置页「元素跟随动画：平滑跟随/即时切换」）；
  用户口述确认："检测窗口、文字大小这些，自动选择区域"（即 Snipaste/Shotera 同款的
  智能选区，本质是此前借鉴清单的「嵌套控件智能识别 UIA」+ 文字块检测的组合）
- 对比我们：有窗口级悬停选中（GDI WindowFromPoint 路线），无控件级/文字块级

### 6.3 一级工具栏（图标化悬浮胶囊，白底圆角大阴影）
从左到右（约 20 个 40px 图标按钮，纯图标无文字）：

| 分组 | 按钮 |
|---|---|
| 移动 | 六点拖拽把手（设置可关，关闭后仍可拖空白边缘） |
| 标注工具 | **形状**（矩形，激活时高亮，二级栏出选项）、箭头、**画笔、荧光笔**、马赛克/色块、**文字 T**、**自动序号 ①**、**Emoji 贴纸 😊**、**局部放大 🔍+**、**橡皮/小刀** |
| AI 动作 | （分隔线）喷涂?/画刷?（待后续截图确认）、**翻译（文A 图标）**、**提取文字（⛶ 图标）** |
| 输出 | **贴图 📌**、（分隔线）撤销 ↶ / 重做 ↷、保存 ⬇ |
| 终止 | **取消 ✕（红）/ 确认 ✓（绿）**——红绿双色是明确的状态语言 |

- 直线/椭圆疑似收纳进形状/箭头工具的二级变体（□/○ 切换），不占一级位（待确认）
- **对比我们**：10 工具 + 色环，文字+图标混排、单级工具栏、属性控件内联。
  Shotera 的一级栏更短（形状合并变体）、AI 动作和输出动作分组明确、红绿终止键醒目
- **用户已定方向**：工具栏/UI 美观度明显优于我们，功能相同的前提下朝它改（本轮讨论后立项）

### 6.4 二级工具栏（上下文属性栏，选中绘图工具时出现）
主工具栏下方再浮一条：六点把手 + **粗细滑条（带数值 12）** + 形状变体切换（□矩形/○椭圆）
+ **线框/填充**切换（□/■）+ **两排预设色板**（黑白灰行 + 彩色行，当前色带圆环高亮）
+ 自定义色按钮（打开完整取色面板）
- 属性上下文随工具变化——这是"一级短工具栏 + 二级属性"的标准分层，比我们把所有属性
  塞一级栏更干净

### 6.5 完整取色面板（自定义色）
HSV 渐变面积 + 色相滑条 + **透明度滑条（棋盘格底）** + **HEXA 输入框（#4F7CFFFF，含 alpha）**
+ 16 色预设网格。
- 对比我们：色环不支持 alpha 与精确色号输入；标注半透明色（荧光笔类效果）需要这套
