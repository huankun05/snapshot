## 一、2026-10 竞品格局速览

| 竞品 | 动向（2025Q4~2026） | 对我们的威胁点 |
|---|---|---|
| **PixPin**（3.4.x） | 截图/贴图/长截图/离线 OCR/GIF/录屏全家桶；**3.0 起接入 AI 大模型（AI 问答、AI 翻译）**；3.4 新增**贴图组**；基础功能全免费无广告 | 最直接对手：功能面与我们几乎完全重叠且免费，AI 先走了一步 |
| **Snipaste** | 经典贴图+标注，轻量稳定；仍无 OCR/长截图/GIF | 不构成威胁，但其贴图手感仍是标杆 |
| **Win11 自带截图** | **2025-04 起内置 Text Extractor OCR**（Win+Shift+S → 文字提取），2026 年已全量 | **抬高基线**：系统免费自带"能提字"，纯 OCR 不再是卖点 |
| **PowerToys Text Extractor** | Win+Shift+T 直接划字，成熟稳定 | 同上，免费基线 |
| **Pot**（开源） | 划词/截图翻译，OCR 引擎可插拔（Google 100+ 语种） | 截图翻译细分赛道的开源对照 |
| **ShareX / Greenshot** | 西方市场免费全功能标杆，持续维护 | 功能清单长但重、学习曲线陡 |
| **Shotera** | 闭源 Tauri 类 + 本地 ONNX（详见 `Shotera竞品调研.md`）；AI 抠图（RMBG 系列）、图片翻译（百度/有道） | 本地 AI 模型产品化的范式参照 |

## 二、趋势判断（2026）

1. **"截图问 AI"成为主流工作流但桌面端无占位者**：ChatGPT/Claude 解读截图（报错、代码、表格）
   已是高频场景，PixPin 只做了"AI 问答"入口，专用截图工具里**还没有把"选区→LLM"做成一等
   动作的成熟产品**。这是当前最明显的空位。
2. **OCR 基线被系统拉平**：Win11 自带文字提取后，竞争点从"能识别"转向**快、准、识别后动作**
   （翻译/表格/排版还原/AI 处理）。
3. **本地化/隐私是差异化卖点**：Shotera（本地 ONNX）与我们的本地 OCR+本地 MT 路线均属此列；
   云端方案（百度/有道）仍是多数竞品的选择，离线全链路是少数派优势。
4. **贴图仍在进化**（PixPin 贴图组、Shotera 贴图恢复栈）：贴图从"钉一张图"走向"贴图管理"。
5. **表格/结构化输出**：agentic OCR（复杂表格→结构化数据）是 2026 OCR 舆论热词，我们已有
   SLANet 表格识别，方向踩对了。

## 三、差距分析 → 改进建议（按优先级）

### A. 补短板（竞品已有、我们没有）

| # | 项 | 依据 | 备注 |
|---|---|---|---|
| A1 | **"选区问 AI"一等动作**（选区→LLM 问答/解释，结果进现有面板） | 趋势 #1；PixPin 3.0 已有 AI 问答 | 复用现有 OCR/结果面板管线，增量最小、差异化最大；用户已有云 MT 凭据体系可复用 |
| A2 | **贴图恢复栈 + F3 双语义**（贴剪贴板/恢复最近关闭） | Shotera 调研借鉴 #1，仍是待实现；PixPin 有贴图组 | 原清单既定项，维持高优先 |
| A3 | **GIF 录制导出** | PixPin/ShareX 标配；我们录屏已有（设置含 recCountdown/recQuality） | 分享场景刚需，可在现有录屏上追加 GIF 编码 |
| A4 | **文件名模板 + 快捷保存 + 自动保存** | Shotera 输出分区（借鉴 #5 后半），PixPin 亦有 | 设置面板 v1 已有架构，接线型工作 |
| A5 | 取色放大镜 | Shotera 第二批 ★★★ | 已在借鉴清单 |

### B. 放大独有优势（我们有什么别人没有/没做好）

| # | 项 | 说明 |
|---|---|---|
| B1 | **长截图闭环** | PixPin 有但口碑一般（大页面易断）；我们 r58~r60 修完**未实测**，一旦闭环即是对 PixPin 的直接对位优势。注意：`frames/` 回放数据重建仍待做，源数据在系统临时目录有被清理风险 |
| B2 | **离线全链路翻译叠图**（本地 OCR + 本地 Hy-MT2 + overlay 回填） | Shotera 翻译是云端、PixPin AI 走云；全离线是隐私/内网友好差异化 |
| B3 | 表格识别 → HTML/Excel 直贴 | 已落地且用户认可；按 A1 思路可追加"表格问 AI"（求和/解读） |
| B4 | 智能选区（UIA+像素混合） | Snipaste 实为 UIA 命中式；我们的混合路线下一步候选：UIA 缓存 + IsHungAppWindow、像素局部邻域（见架构记忆） |

### C. 健壮性欠账（市场格局之外，但影响口碑）

1. **启动 cwd 脆弱**：dist `getCaptureHtmlPath()` 候选路径缺 `../../resources`（=screenshot\resources），
   非 screenshot 目录启动即 capture.html NOT FOUND（2026-10-02 与 2026-10-27 两次依赖 cwd 正确）。
   一行候选路径补丁可根治，建议尽快修。
2. **多 DPI 脆弱点**（2026-10-08 实测记录）：cursorInCapture DIP/物理混用（偏 171px 场景）、
   winBox÷主屏 sf 假设、>4000px 选区 OCR 缩 0.78×。
3. **版面/智能识别质量**：PP-StructureV3 弃用后智能识别（PP-DocLayoutV3）v1 已落地，双栏阅读
   顺序、区域边界等仍待实测调优；UI 噪音（按钮文字）过滤待做。

## 四、用户自测清单（配合本轮重启，2026-10-27）

> 启动已验证：`capture page loaded (persistent)` + `热键 F1: 已注册` + 设置读取正常。

1. F1 智能选区：多应用窗口悬停（含浏览器、IDE、聊天窗），确认高亮跟随与选链层级。
2. OCR 三动作：默认文本 / 表格识别（HTML 贴 Excel）/ 智能识别（双栏页面看阅读顺序）。
3. 翻译叠图：首次调用延迟应可接受（WDDM 回退看门狗生效性观察）；**同一图重访应明显变快**
   （LRU 缓存，重访 ~400ms 量级）。
4. **长截图（本轮重点）**：浅色页 / 深色稀疏页 / 吸附式页面 / 有 hover 干扰页面各来一次
   ——r58~r60 全部"已修待实测"，这是最需要用户手感的板块。
5. 双屏跨屏选区对齐复测（r61 偏移修复确认；主屏 125% + 副屏 150%）。
6. Alt+C 截图并复制、录屏（3s 倒计时）、贴图缩放拖动。
