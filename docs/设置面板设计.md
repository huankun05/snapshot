# 设置面板设计（v3 · 拾花专属）

> 目标：给「拾花 PetalSnap」做**有自己特色**的设置面板——Shotera 只作结构与控件纪律参考，
> **内容主体是拾花独有能力**（长截图 / 录屏 / 表格 / 智能版面 / 本地叠图翻译）。
>
> v2 被用户否掉的两点，本文已改：
> ① 图标必须用应用真图（`resources/icon/logo-256.png` / `petalsnap-master.png`），不用占位花；
> ② 不能整页照抄 Shotera——要写进我们独有、且已有代码路径的设置。
>
> 原则不变：标题+说明+右控件 / 即时生效无确定钮 / **不放死设置** / 说明写清行为·生效·副作用。

### 3.2 截图

| 设置 | 控件 | 默认 | 说明文案 | 实现 |
|---|---|---|---|---|
| 截图热键 | 键帽+绿勾 | Alt+Q | 全局生效；冲突自动降级备用键，以托盘显示为准；点击后按新键，Esc 取消 | `screenshot-hotkey` 即时重注册 |
| 抓帧引擎 | 下拉 | 自动（推荐） | 优先原生插件，失败回退 GDI；黑屏/偏色可强制 GDI，下一次截图生效 | `screenshot-engine` |
| 截图后自动识别 | toggle | 关 | 框选确定后自动执行「默认识别动作」并打开结果面板；手动识别不受影响 | `screenshot.ocr-auto` |

### 3.3 长截图 ★ 独有

| 设置 | 控件 | 默认 | 说明文案 | 实现 |
|---|---|---|---|---|
| 默认自动滚动 | 分段 开/关 | 开 | 进入长截图即开始匀速自动滚动拼接；关则改为你自己滚页面、我们跟帧拼接。会话中控制条仍可临时切换 | `screenshot.ls-autoscroll`；读 `lsAutoScrollOn` 初值 |
| 自动滚动步长 | 分段 标准/更密/更快 | 标准 | 每格位移约占选区高度的比例：标准最稳（重叠大）；更密更清晰更慢；更快省帧但可能断档。拼接失败时先退回「标准」 | `screenshot.ls-step` → `lsAutoTargetFrac`（0.28/0.35/0.45） |
| 结束后默认动作 | 分段 进入编辑器/直接复制 | 进入编辑器 | 点「完成」或到底自动结束时：编辑器可继续标注；直接复制则进剪贴板并退出 | `screenshot.ls-on-done`（二期可先做 UI+接 stop 分支） |

> 注：步长/结束后动作若本轮接线赶不上，UI 可先标「即将支持」——**更稳妥是与功能接线同 PR**。v3 视觉稿全画。

### 3.4 录屏 ★ 独有

| 设置 | 控件 | 默认 | 说明文案 | 实现 |
|---|---|---|---|---|
| 开始前倒计时 | 分段 0/1/3/5 秒 | 3 秒 | 点录屏后先显示倒计时，便于切到被录窗口；0 = 立即开始 | `screenshot.rec-countdown`；替换硬编码 3 秒 |
| 画质 | 分段 流畅/均衡/清晰 | 均衡 | 影响 WebM 码率与体积：流畅约 4Mbps，均衡约 8Mbps，清晰约 16Mbps（上限仍受分辨率约束） | `screenshot.rec-quality` → 替换 `recBitrate` 公式档位 |
| 保存方式 | 分段 每次询问/固定文件夹 | 每次询问 | 询问=每次弹「另存为」；固定文件夹=直接写入下方目录并 toast 文件名（省一次点击） | `screenshot.rec-save-mode` |
| 保存文件夹 | 路径 + 打开 | 系统「视频」 | 仅「固定文件夹」模式生效；默认 `app.getPath('videos')` | `screenshot.rec-save-dir` + `settings:pickFolder` / `openPath` |
| 文件名前缀 | 输入 | `拾花录屏` | 固定文件夹模式下的文件名前缀，后缀为时间戳 `.webm` | `screenshot.rec-filename-prefix`；替换 `eIsland_recording_` |

### 3.5 识别

| 设置 | 控件 | 默认 | 说明文案 | 实现 |
|---|---|---|---|---|
| 识别引擎 | 单选卡 RapidOCR/Tesseract + 云下拉 | RapidOCR | 本地 RapidOCR（内置·离线）最佳；Tesseract 兼容；云端需网 | `screenshot-ocr-engine`（值仍 `paddleocr`） |

| 默认识别动作 | 下拉 文字/表格/智能 | 文字识别 | 工具栏识别主按钮执行的动作；▾ 菜单仍可选其余 | `screenshot-ocr-default-action` |
| 表格复制格式 | 分段 带边框 HTML / 纯 TSV | 带边框 HTML | 表格识别后「复制」的默认格式：HTML 可直接贴 Excel/WPS 且有边框；TSV 适合粘贴进记事本/表格纯文本 | `screenshot.table-copy-format` |

| 服务状态 | 状态行 + 日志/重启 | — | 运行状态（GPU/CPU、端口、build）；异常可重启 | `ocr:health` / `ocr:restart` |
| **模型清单** | 就绪/按需下载徽章 + 来源 + 体积 | — | 各模型是否在本机；按需下载的首次使用对应功能时自动拉取，下载完即可用 | `/health.models` |

### 3.3a 模型来源与下载策略（2026-09-17）

| 模型 | 用途 | 体积 | 获取 | 渠道 |
|---|---|---|---|---|
| PP-OCRv6-small | 文字识别 | ~31MB | 随 rapidocr 包内置 | PyPI wheel `models/` |
| PP-DocLayoutV3 | 智能版面 | ~125MB | 首次智能识别自动下载 | ModelScope RapidAI/RapidLayout；缓存 rapid_layout/models/ |
| SLANet-plus | 表格 | ~8MB | 首次表格识别自动下载 | rapid_table 默认模型 |
| Hy-MT2 GGUF | 本地翻译 | ~1.1GB | 外部文件 | `D:\llama\models\Hy-MT2-1.8B-Q4_K_M.gguf`；缺失时设置页显示路径说明 |

原则：大模型不打进安装包；缺则首次用到时自动拉/提示路径；小 OCR 模型随包保证开箱能识字。翻译模块已恢复 `screenshot_tool/mt_engine`（自归档拷回最小包）。

## 四、UI 样式要点（v3.1）

1. **品牌图标**：左导航顶 + 标题栏 + 关于页，一律使用 `resources/icon/logo-256.png`（粉樱水彩主稿）。
2. **配色已定（2026-09-17）**：不用纯白素面 Shotera 克隆，也**不整页染粉**——
   - 右区底 `#F7F4F5` 极浅暖灰粉；**卡片保持纯白**（长说明可读性优先）
   - accent 玫粉 `#C45A7A`（自 logo 花瓣取色）；分段选中 / 键帽 / 导航活动项 / 链接统一
   - 窗口顶 3px 樱粉渐变细线 + logo 本身作品牌锚点；提示卡淡粉底
   - **不放**「拾花独有」徽章 / ✦ 角标（信息冗余，观感怪）
3. 分区图标 Lucide 描边；长截图 / 录屏 用 scroll-text / video。
4. 截图浮层仍用 `UI设计方案.md` 的 `#3D6BE5`（压在桌面内容上对比更稳）；**设置窗是应用壳，允许品牌粉**——两套表面角色不同，不必强行同色。
