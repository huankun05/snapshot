## A. 设置页（2026-11-25 第二轮：按用户实测反馈修复）

- [ ] **A1 备份时间正确**
  - 怎么测：点「立即备份」→ 看列表时间是否等于当前时间；再到备份目录看文件名年份。
  - 通过：列表时间 = 刚才的本地时间；文件名形如 `settings-2026-11-25-15-40-12.json`（**不再是 2001 年**）。
  - 背景：F2 原手写日期算法把年份算成 2001（磁盘上真有 `settings-2001-12-06-…`）；F1 原用 UTC，与显示差 8 小时。现双壳都用本地时间，列表时间改从文件 mtime 取，不再解析文件名。
- [ ] **A2 删除备份 + 撤销**
  - 怎么测：备份行点「删除」→ 该行消失、底部提示「已删除该备份」→ 点提示里的「撤销」。
  - 通过：不弹确认框；撤销后文件原样回到目录（内容一致）；超过 6 秒提示消失后再删则无法撤销（宿主保留 60 秒）。
- [ ] **A3 跨壳备份保护（重要）**
  - 怎么测：把 F1 生成的备份拿到 F2 恢复（或反过来）。
  - 通过：**默认被拦下**，提示「这是 Electron/Tauri 壳的备份…建议按键合并」，并给「仍要恢复（合并）」按钮；点合并后只覆盖同名键，**当前壳其它设置不丢**。
  - 旧备份（无壳标记）同样走合并，不做整体替换。
- [ ] **A4 反馈浮层不再重复**
  - 怎么测：鼠标悬停在某个设置卡片上（出说明浮层）→ 保持悬停时点一个按钮（如刷新/备份）。
  - 通过：屏幕上**不会同时挂两条浮层**；说明浮层跟随锚点，操作反馈固定在**面板下方居中**，各自消失互不影响。
  - 背景：两者原共用同一个 DOM id，会各建一个同 id 元素，定时器只清得掉第一条。
- [ ] **A5 模型下载按钮可见**
  - 怎么测：看「模型与语言包」里未下载的表格/版面模型行。
  - 通过：右侧有独立「下载」按钮（不再被长路径挤出窗口）；路径单行省略号，悬停可看全文；点下载能起进度并落地。
- [ ] **A6 备份列表 + 一键恢复（上一轮修的必败路径，回归）**
  - 通过：列表能读出条目（不再恒「读取失败」）；同壳恢复后设置真的回滚。

## B. 长截图迁移（7.1，F2 新实现）

- [ ] **B1 网页长截图基本流**
  - 怎么测：浏览器打开一个长页面 → 截图框选页面内容区 → 点「长截图」→ 等自动滚动拼接 → 按 Enter 完成。
  - 通过：编辑器里是一条完整长图，接缝处无重复行/错位；**鼠标光标不被移动**（滚轮走消息注入）。
  - 不对时：`%TEMP%\petalsnap-spike.log` 搜 `[ls]`，看 `WM_MOUSEWHEEL` 是否命中 `Chrome_RenderWidgetHostHWND`、拼接帧数与停止原因。
- [ ] **B2 取消与兜底**：长截图进行中按 Esc → 应立即停止且不残留贴图/热键；再截一次普通图应正常。
- [ ] **B3 超限拆分**：截一个超长页面（超过高度上限）→ 应按上限拆分保存多张，不崩不卡。
- [ ] **B4 非浏览器窗口**：对资源管理器/设置窗口做长截图 → 允许效果一般，但不得卡死或吞鼠标。
- 备注：区块删除（PixPin 3.4 同款）是 **7.1b**，本轮未做，不在验证范围。

## C. 表格富文本复制（7.2，CF_HTML）

- [ ] **C1 粘进 Excel / WPS 表格**
  - 怎么测：截一张表格 → OCR（表格模式）→ 点复制 → 到 Excel/WPS 里 Ctrl+V。
  - 通过：落成**多行多列带边框的表格**，而不是一坨文本挤在一格。
  - 不对时：先粘到 Word 看是否带格式（区分是 CF_HTML 没写进剪贴板，还是目标程序不认）；日志搜 `cf_html` / `clipboard`。
- [ ] **C2 纯文本回退**：同一份结果粘到记事本 → 应是可读的制表/换行文本，不出现 HTML 标签。

## D. 隐私快速打码（7.3，唯一含估算的环节）

- [ ] **D1 候选框位置准确性（重点）**
  - 怎么测：截一张同时含**手机号、邮箱、身份证、银行卡、QQ/微信号、地址**的图 → OCR → 点「隐私打码」。
  - 通过：每个候选框**横向**落在对应号码上（纵向由行框保证）。这是全链路唯一靠字符宽度权重估算的环节，**最需要你的眼睛**。
  - 不对时：告诉我偏移方向与大致比例（偏左/偏右、约几个字符），我改权重或改成整行打码 / 加左右微调手柄。
- [ ] **D2 点击打码 / 再点还原**：点候选框 → 该处变马赛克；再点同一处 → 还原原像素。
- [ ] **D3 撤销链**：打码后 Ctrl+Z 应能撤销，且与手工马赛克笔共用同一条历史。
- [ ] **D4 导出已烘焙**：打码后保存/复制 → 输出图里马赛克是**真的烧进像素**的，不是浮层。
- [ ] **D5 失效与禁用**：改变选区后候选层应消失；用没有行框的引擎时「隐私打码」按钮应置灰。
