## 七、❌ 未迁移缺口看板（每项可直接单开对话实施，引用条目名即可）

> 格式：目标 / 范围 / 依赖 / 工时 / 验收。按建议优先级排序；✅ 项已完成存档。

### 7.1 ★ 长截图迁移（建议下一个对话直接做）
- 目标：F2 工具栏长截图按钮从 notPorted 变为全功能（自动滚动拼接 + 编辑器 + 保存）
- 范围：Rust 侧 7 通道（capture-longshot-gdi/-frame/-save/-editor、capture-ls-autoscroll/-debug/-active）——
  滚轮注入循环（PostMessage，UIPI 管理员窗口风险）、选区抓帧循环（复用 capture_virtual_screen）、
  编辑器窗口（新 webview，渲染端长截图编辑态同源已有）、帧落盘
- 依赖：无（渲染端 capture.js 长截图 UI/状态机同源已有，零改动预期）
- 工时：1.5~2 天（含真实页面闭环实测：浅色页/深色稀疏页/吸附式页/轮播页）
- 验收：F1 同场景 A/B 对比拼接结果；`tools/` 长截图回归四件 42/17/5 全绿
- 注意：渲染端两份同步铁律；F1 的 r58~r60 修复是否需要同步进 F2 无需额外处理（同源自动带入）

### 7.2 CF_HTML 富文本（表格粘贴）
- 目标：表格识别/文字识别复制时带 CF_HTML 格式，粘贴到 Excel/WPS 保留表格结构
- 范围：Rust 剪贴板写入加 RegisterClipboardFormat(CF_HTML) + HTML 包装（Windows 剪贴板多格式）
- 依赖：无
- 工时：0.5 天
- 验收：复制表格 → Excel/WPS 粘贴带边框表格（F1 现状对照）

### 7.3 录屏迁移
- 目标：选区录制 H.264 MP4（30/60fps + 麦克风/系统声）
- 范围：Media Foundation sink writer（青蛙已验证纯系统编码器路线）+ 音频捕获 + 编辑器窗基建
- 依赖：7.1 的编辑器窗基建（共用）
- 工时：1~1.5 天
- 验收：F1 同参数录制对照（画质/音轨/文件大小）

### 7.4 放大镜贴片（标注家族扩展，backlog）
- 目标：标注菜单新件——把锚点区域 2× 放大贴在旁边（演示/指认细节）
- 范围：标注层新 shape 类型（bake 时从 bgCanvas 取像素放大画入 drawCtx）
- 依赖：无（getMergedCanvas 模式已有）
- 工时：1 天
- 验收：标注拖拽/缩放/烘焙/撤销全手势回归

### 7.5 设置互通 store 双写（迁移方案 §4.3）
- 目标：F1/F2 设置互相可见可写（现在 F2 只读继承凭据类）
- 范围：store 路径统一或镜像写入；冲突策略（最后写赢）
- 依赖：无
- 工时：0.5 天
- 验收：F1 改热键 → F2 设置页即时反映；F2 改 → F1 反映

### 7.6 桌面源枚举 / 云引擎 / 外部触发 / 校准工具
- 建议优先级：低（desktopCapturer 回退路径 / 本地优先战略 / 灵动岛集成 / 调试工具）
- 每项 0.5~1 天，按需单开对话
