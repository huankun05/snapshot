## 七、❌ 未迁移缺口看板（每项可直接单开对话实施，引用条目名即可）

> 格式：目标 / 范围 / 依赖 / 工时 / 验收。按建议优先级排序；✅ 项已完成存档。

### 7.1 ★ 长截图迁移（建议下一个对话直接做）
- 目标：F2 工具栏长截图按钮从 notPorted 变为全功能（自动滚动拼接 + 编辑器 + 保存）
- 范围：Rust 侧 7 通道（capture-longshot-gdi/-frame/-save/-editor、capture-ls-autoscroll/-debug/-active）——
  滚轮注入循环（PostMessage，UIPI 管理员窗口风险）、选区抓帧循环（复用 capture_virtual_screen）、
  编辑器窗口（新 webview，渲染端长截图编辑态同源已有）、帧落盘
- **验收线抬高（2026-11-24 竞品调研 §四）**：编辑器须带**实时缩略预览窗**（QQ 同款）与
  **框选删除中间区块、上下自动衔接**（PixPin 3.4 同款，去广告/重复段落）——编辑器窗口反正要新建，
  这两项边际成本低，事后补要再动一次状态机
- 依赖：无（渲染端 capture.js 长截图 UI/状态机同源已有，零改动预期）
- 工时：1.5~2 天（含真实页面闭环实测：浅色页/深色稀疏页/吸附式页/轮播页）
- 验收：F1 同场景 A/B 对比拼接结果；`tools/` 长截图回归四件 42/17/5 全绿；缩略预览与区块删除各实测一次
- 注意：渲染端两份同步铁律；F1 的 r58~r60 修复是否需要同步进 F2 无需额外处理（同源自动带入）

### 7.2 CF_HTML 富文本（表格粘贴）
- 目标：表格识别/文字识别复制时带 CF_HTML 格式，粘贴到 Excel/WPS 保留表格结构
- 范围：Rust 剪贴板写入加 RegisterClipboardFormat(CF_HTML) + HTML 包装（Windows 剪贴板多格式）
- 依赖：无
- 工时：0.5 天
- 验收：复制表格 → Excel/WPS 粘贴带边框表格（F1 现状对照）

### 7.3 ★ 隐私快速打码（竞品调研 N1，建议插队在录屏前）
- 目标：OCR 面板一键找出截图里的隐私信息并打码（QQ 自动打码 + Win 快速修订的本地版）
- 范围：识别完成后对结果正则扫 手机号/邮箱/身份证/银行卡/QQ号 → 用词级坐标在图上高亮候选块 →
  点击写入马赛克 annotation（复用现有打码 shape 与撤销），再点取消；**默认只提示不自动打**
- 依赖：无（词级坐标 OCR 结果已有；纯本地零新模型）
- 工时：1 天
- 验收：含手机号+邮箱的截图 → 候选块全部命中、点击打码/取消正确、撤销可用、导出图已烘焙

### 7.4 识别结果「文本操作」层（竞品调研 N2）
- 目标：OCR 从「识别完弹个窗」变成「每次都愿意点」
- 范围：面板加 去换行 / 识别后自动复制 / 复制为纯文本·Markdown·保留换行 三个开关，选择持久化
- 依赖：无
- 工时：0.5 天
- 验收：英文段落去换行正确；开关重启后仍在；自动复制不覆盖用户随后手动复制的内容（clipboardSeq 守卫）

### 7.5 表格结果轻量编辑（竞品调研 N3）
- 目标：给 SLANet 表头并格等已知残留一个 10 秒手工修正出口
- 范围：结果 HTML 表格上删行/删列/合并单元格；编辑结果参与 CF_HTML 复制（7.2）
- 依赖：7.2
- 工时：1 天；xlsx 导出列 backlog
- 验收：并格表头手工拆合后粘贴到 Excel 结构正确

### 7.6 贴图增强四件（竞品调研 N4）
- 目标：贴图支持「边对照边操作」
- 范围：鼠标穿透 / 缩略图（Shift+双击）/ 旋转·镜像 / 文本与色值贴图；pin.js 双份同步
- 依赖：无（纯渲染端 + 窗口属性，不碰 IPC 契约）
- 工时：1 天；GIF·WebP 播放与贴图分组列第二批
- 验收：四件各实测一次；穿透后可用快捷键还原；贴图透明度记忆不回归

### 7.7 公式识别问 AI 模板（竞品调研 N5）
- 目标：截图公式一键转 LaTeX / Typst
- 范围：`resources/ask-ai-modes.json` 加两模板（system prompt + temperature），OCR ▾ 菜单出现入口
- 依赖：用户自配 OpenAI 兼容凭据（沿用问 AI 现有链路）
- 工时：0.2 天；本地公式模型暂不引入
- 验收：行内/块级公式各一张，LaTeX 可编译、Typst 语法正确

### 7.8 保存文件名模板 + 复制并保存（竞品调研 N6）
- 目标：保存不再每次手敲文件名；复制与落盘一次完成
- 范围：保存卡加文件名模板（`%yyyy%-%MM%-%dd_%HH%%mm%%ss`、窗口标题变量）+「复制并保存」开关
- 依赖：设置页「保存」分组（2026-11-23 已落地）
- 工时：0.5 天；**不做 ShareX 式完整任务链**
- 验收：变量展开正确、非法文件名字符过滤、对话框默认路径仍读 screenshot-save-dir

### 7.9 录屏迁移
- 目标：选区录制 H.264 MP4（30/60fps + 麦克风/系统声）
- 范围：Media Foundation sink writer（青蛙已验证纯系统编码器路线）+ 音频捕获 + 编辑器窗基建
- **验收线抬高（2026-11-24）**：**MP4/GIF 双导出 + 异常退出可恢复录制内容**（PixPin 3.5 / QQ 同款）
- 依赖：7.1 的编辑器窗基建（共用）
- 工时：1~1.5 天
- 验收：F1 同参数录制对照（画质/音轨/文件大小）；强杀进程后重开能恢复录制

### 7.10 放大镜贴片（标注家族扩展，backlog）
- 目标：标注菜单新件——把锚点区域 2× 放大贴在旁边（演示/指认细节）
- 范围：标注层新 shape 类型（bake 时从 bgCanvas 取像素放大画入 drawCtx）
- 依赖：无（getMergedCanvas 模式已有）
- 工时：1 天
- 验收：标注拖拽/缩放/烘焙/撤销全手势回归

### 7.11 设置互通 store 双写（迁移方案 §4.3）
- 目标：F1/F2 设置互相可见可写（现在 F2 只读继承凭据类）
- 范围：store 路径统一或镜像写入；冲突策略（最后写赢）
- 依赖：无
- 工时：0.5 天
- 验收：F1 改热键 → F2 设置页即时反映；F2 改 → F1 反映

### 7.12 桌面源枚举 / 云引擎 / 外部触发 / 校准工具
